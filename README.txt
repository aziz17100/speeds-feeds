CNC Speeds & Feeds - installable app (PWA)

1) Upload ALL the files in this folder to a free static host:
   - GitHub Pages: create a repository, upload the files, Settings > Pages > Deploy from branch (main, / root).
   - or Netlify: app.netlify.com/drop (free account), drag the folder in.
2) Open the https link in Chrome on your Android phone.
3) Chrome menu (three dots) > "Add to Home screen" / "Install app".

Files: index.html, manifest.webmanifest, sw.js, icons/
